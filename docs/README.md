# ALE-docs

This folder contains the documentation for [Arcade-Learning-Environment](https://github.com/Farama-Foundation/Arcade-Learning-Environment).

## Editing an environment page

The pages in `docs/environments/` are generated by `docs/_scripts/gen_environments_md.py`. To change a game's description, reward description or starting condition, edit its entry in `docs/_scripts/environment-docs.json`; to change the text shared by all pages, edit the template in the script. Then, with `ale-py` installed, regenerate the pages:

```
cd docs/_scripts
python gen_environments_md.py
```

## Build the Documentation

Install `ale-py` and the required packages:

```
pip install .
pip install -r docs/requirements.txt
```

To build the documentation once:

```
cd docs
make html
```

To rebuild the documentation automatically every time a change is made:

```
cd docs
sphinx-autobuild -b html . _build
```
